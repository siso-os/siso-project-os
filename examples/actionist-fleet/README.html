Actionist fleet dog-food

This is a public-safe, non-authoritative migration rehearsal derived from capability and gap categories observed in the Actionist programme on 2026-08-30. Repository revisions, actor identities, provider workspace names, and repository locators in this fixture are synthetic; no live topology or private source identifier is included. It does not mutate the live programme, create a second registry, or authorize a conversion wave.

Run npm run dogfood:fleet. The script creates temporary parent and nested Git repositories, replaces placeholder candidate hashes with those temporary commits, installs this fleet configuration, directly verifies candidate commits and evidence, records one verifier eligibility receipt and one claim-bound dependency-held conversion receipt, checks the projections, prints a JSON result, and removes only its temporary directory.

What the comparison proves

  • The prior programme already had intent, domains, a dependency graph, exclusive owners, callbacks, machine placement, and readiness gates.
  • The pack normalizes those practices into portable Project OS contracts without claiming ownership of Herdr or Great Library state.
  • An explicitly configured verifier whose identity differs from the implementation actor and domain owner remains eligible while a write-claimed conversion candidate stays held behind incomplete dependencies.
