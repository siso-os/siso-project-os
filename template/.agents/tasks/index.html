Task registry

Each task lives at .agents/tasks/<lifecycle>/TASK-NNNN/task.json with an append-only events.jsonl and evidence directory.

Lifecycle

Hard states are backlog, in_progress, blocked, completed, and cancelled. Folder, embedded ID, and status must agree. Archived is a storage disposition that preserves completed or cancelled.

Mutations

ID allocation, create, update, dependency-ready claim-next, and archive hold the registry lock. Claim-next skips explicit human gates unless opted in. Archive requires actor and reason, supports dry-run, and refuses destination collisions.
