Runs

A run is one execution attempt linked to canonical tasks and optionally a sprint.

RUN-YYYY-MM-DD-slug/
  run.json
  queue.json
  ledger.jsonl
  briefs/
  returns/
  evidence/
  attempts/<unit>/attempt-<n>/attempt.receipt.json
  attempts/<unit>/attempt-<n>/verification.receipt.json
  attempts/<unit>/attempt-<n>/result.json

Packets are immutable; amendments are new packets. Queue unit state mirrors run.json and retains packet digests. Closeout refuses non-terminal attempts, active claims, modified packets, unresolved gates, unclassified outputs, or landed work without independent verification and remote-equality proof.
