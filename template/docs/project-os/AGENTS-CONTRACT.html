Project-local agents contract

One Project OS route for durable work, cold pickup, verification, and auditable projections.

Canonical writers

Tasks live in .agents/tasks/**/task.json; runs and receipts live under .agents/; durable knowledge lives under docs/ and .agents/memory/. Generated HTML/JSON is never an alternate writer.

Cold pickup

Read root rules, PROJECT-OS.html, FILE-TREE.html, onboarding, one canonical task, and only its linked execution context. Scratch, raw history, generated views, and optional capabilities are pointer-addressed.

Boot boundary

AGENTS.md, CLAUDE.md, and SKILL.md are routing shims to one operator authority. Audit requires duplicate_authorities=0, competing_boot_sequences=0, and a bounded context producer.
