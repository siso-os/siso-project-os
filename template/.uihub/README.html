UI Lab operating map

Task-linked UI decisions and proof, never a parallel backlog.

State machine

intent → research → directions → candidates → review → decided → implemented → verified

superseded is terminal and preserves history.

Canonical and generated records

  • campaigns/UI-####/campaign.json is canonical campaign state.
  • candidates/manifest.json accounts for every bounded candidate.
  • review/response.json is raw human evidence.
  • decided/decision.json freezes a complete choice.
  • Implementation, verification, and task-evidence fold receipts prove landing.
  • generated/UI-####/gallery.html and review.html are reproducible views.

Rules

  • Compare the same screen, copy, data, shell, state, and viewports.
  • Generated output never implies approval.
  • The review page downloads JSON and holds no browser-local canonical state.
  • Verification proves the chosen direction at the implementation commit.
  • Promoted task evidence resolves by task ID and stable filename, not lifecycle-folder path.
  • Campaign verification never changes task status implicitly.
