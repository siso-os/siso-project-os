A bounded Project OS route for durable project work, cold pickup, verification, and auditable projections.

Generated HTML/JSON is never an alternate writer. Existing product, runtime, provider, credential, and global-host authorities remain outside Project OS.

Cold pickup

  1. Read root rules and PROJECT-OS.html.
  2. Read FILE-TREE.html and run project-os onboard --json.
  3. Open one canonical task and only its linked mission, run, claim, and verification context.
  4. Reserve the concrete write fence, execute, independently verify, build, check, and hand off.

Scratch, raw history, generated views, and optional capability inventories are pointer-addressed, not automatically appended to prompts.

Boot and context boundary

AGENTS.md, CLAUDE.md, and SKILL.md are routing shims. There is one Project OS operator authority. The contract audit must report duplicate_authorities=0, competing_boot_sequences=0, and a bounded context producer; unknown measurements fail closed.

Auditable projection

project-os build computes deterministic JSON/HTML from canonical repository-relative inputs. project-os check --json recomputes expected bytes in memory and reports drift without repairing. Outputs carry generator and digest metadata where supported.
