Extraction roadmap

Reusable invariants are clean-room reimplemented as generic contracts. Product facts, source scripts, credentials, history, and machine state never become package contents.

Shipped project core

  • HTML-first operating/onboarding routes plus read-only JSON onboarding.
  • Canonical task, sprint, run, UI, proof, and documentation records.
  • Bounded deterministic cockpit and anti-drift checks.
  • Atomic task allocation and one-writer lifecycle rules.

Shipped by the docs/UI completeness lane

  • 24-area sanitized public coverage contract and exhaustive private tracked-path disposition ledger.
  • HTML-first repo facts, edit maps, knowledge routes, adoption/migration, and UI guides with embedded JSON.
  • Bounded joined anti-amnesia/capability/resume/verifier projection helpers.
  • Candidate manifests, deterministic gallery/review renderers, imported response contract, exhaustive decisions, same-commit receipts, and task-evidence folding.

Shared integration still required

  • Wire joined knowledge/capability/resume outputs into build/check/onboard.
  • Wire UI campaign projections and completion problems into build/check/CLI.
  • Remove legacy Markdown routes from shared README/console boot lists.

Remaining execution integrity

  • Mission ownership and immutable resume snapshots.
  • Executable sprint/run lanes, packets, returns, gates, and terminal census.
  • Normalized write reservations.
  • Independent verification and serialized landing.
  • Safe worktree/bootstrap, landing plan, archive, and durable failure adapters.

Deliberate boundary

Agent Base owns models, spawning, supervision, messaging, telemetry, terminals, and credentials. Project-local adapters own product commands and policy. Project OS owns durable project records, checks, and deterministic read surfaces.
