One repository front door

The spine makes a project's purpose, current owner, evidence, repositories and published page discoverable after its agents leave. It extends the existing task and recovery contracts.

PathOwns
.agents/PAGE.mdShort project introduction, current outcome, owner, entry/run/test commands and links. Review its content before rendering a public page.
.agents/HANDOFF.mdRoute to the owner's existing handoff, or the first handoff when none exists. Keep one current-state writer.
.agents/repos.jsonCanonical repository URL, parent URL, Library Work ID and satellite repositories with roles and visibility. Null means not recorded; private locators do not grant access.
.agents/owners.logAppend-only material-change index: ISO timestamp with timezone · OWNER · what · evidence path. The installed writeback skill can mirror the exact line to the coordinator's existing ledger.
.agents/page.urlOne verified HTTPS publication URL, or an empty file before publication. Deployment failure must not replace a previous working URL.
intake/Project intake governed by the project's visibility and data policy.

Install and verify

npx --yes github:sisodias/siso-project-os#v0.4.1 init . --name "My Project"
npx --yes github:sisodias/siso-project-os#v0.4.1 check . --json

For an existing project use adopt plan and adopt apply. They preserve every different spine file and report the collision. Read and reconcile the existing owner route before adopting a new template. Upgrades retain edited files.

GitHub template versus installed project

The GitHub template repository contains the reusable kit, including its installer and template/ payload. Creating from that repository copies the kit; it does not execute the installer or configure a project for you. To create a project directly, initialize an empty repository with the pinned command above. To develop or customize the kit, use GitHub's template action and run the local installer into the intended project directory.

Repository links and publication

Each satellite links back to its owning project by URL. Each project links to its parent and Library identity. Source words and agent sessions stay in their declared data repositories with independent privacy and rights review. The template creates no remote repositories, live agents or publication by itself.

Build reviewed public content using the pinned SISO Shell and publish the static output through the installed publish skill. Store its verified URL in page.url and its receipt in the owner's handoff. Private client intake, raw conversations and credentials must not enter public output.

The two compact Markdown entry files are an explicit exception to the kit's HTML-first document convention; tasks, run records and generated pages keep their existing canonical owners.
